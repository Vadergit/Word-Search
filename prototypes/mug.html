The Mug is fully local to the GitHub Pages project and no longer depends on Three.js or a CDN. Letters use the same Android-safe renderer as Pyramid and Orb.

Controls

Rotate: drag empty space around the Mug. The object stays centred while rotating.

Select: the 6×6 grid uses the Cube's eight-neighbour rule, including diagonals.

Quick check: double-tap empty viewport space to run Check word without scrolling.

Trail: selected tiles turn mint and the rounded trail follows the tapered Mug surface.
