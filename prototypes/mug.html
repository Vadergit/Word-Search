The 36 playable cells remain separate curved cylinder patches. The letter texture is optically centred using the actual glyph bounds instead of a fixed baseline offset.

Controls

Rotate: drag empty space around the mug. Vertical rotation is constrained so the controls never flip over.

Select: the 6×6 grid uses the Cube's eight-neighbour rule, including diagonals.

Trail: selected tiles turn mint and the rounded trail follows the tapered mug radius between letters.
