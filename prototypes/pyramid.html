Target words

64 triangles

Each side is subdivided into a true 4×4 triangular mesh. Letters are optically centred on the actual triangle centroid and use Android-safe canvas rendering.

Controls

Rotate: drag empty space around the object. Vertical rotation is constrained so the controls remain consistent instead of flipping over.

Select: tap a touching tile. Selected tiles turn mint immediately and the path uses the same rounded mint stroke with underlay as the Word Cube.

Quick check: double-tap empty viewport space to run Check word without scrolling.

Backtrack: tap a tile already in the active path to jump back, matching the Cube interaction.
