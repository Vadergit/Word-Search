All 42 letters belong to the target-word set. The controls are free again like the Cube: every touching tile can be selected. The generator itself prevents same-letter ambiguity on target routes, so the intended next letter has only one matching neighbouring tile.

Controls

Rotate: drag empty space. Horizontal rotation stays continuous; vertical rotation is limited before the object can go over the top.

Select: tap any touching tile, just like the Cube.

Target uniqueness: the board layout is validated so the next required letter of a target does not appear on a second neighbouring tile.
