Target words

42 / 42 tiles used

All 42 letters belong to the target-word set. In addition to exact-route enforcement, each route is now prevalidated so the next required letter cannot appear on a second neighbouring tile. There is therefore no visually plausible same-letter alternative at any step.

Controls

Rotate: drag empty space. Horizontal rotation stays continuous; vertical rotation is limited before the object can go over the top.

Select: start on a target route. The next required letter is unique among all neighbouring tiles.

Wrong tile: a non-route neighbour is rejected immediately and is never added to the active path.
